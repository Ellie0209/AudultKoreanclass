# 성인 외국인 학습자를 위한 한국어 온라인 강좌 — 전체 교육과정 개요

## 1. 강좌 소개

| 항목 | 내용 |
|---|---|
| 강좌명 | 생활 한국어 첫걸음 (Survival Korean for Adult Learners) |
| 대상 | 한국어를 처음 배우는 성인 외국인 학습자 (TOPIK 0~1급 수준) |
| 수업 형태 | 실시간 화상 수업 (Zoom/Google Meet) + 자기주도 온라인 학습 앱 병행 |
| 총 차시 | 5차시 (차시별 50분) |
| 사용 언어 | 한국어 70% + 영어 30% (초반에는 영어 비중을 높이고 점차 한국어 비중 확대) |
| 교재 | 본 저장소의 `lesson-plans/` 지도안 + `app/` 온라인 학습 앱 |

## 2. 교육 목표

1. 실생활에서 바로 사용할 수 있는 생존 한국어 표현을 익힌다.
2. 한글 읽기·쓰기의 기초를 다지고, 정확한 발음을 연습한다.
3. 인사, 자기소개, 숫자·시간, 쇼핑, 음식 주문, 길 묻기 등 실용 주제를 다룬다.
4. 학습자가 스스로 복습할 수 있도록 온라인 앱을 통한 어휘·문법·퀴즈 연습을 제공한다.

## 3. 차시별 구성

| 차시 | 주제 | 핵심 문형 | 연계 앱 레슨 |
|---|---|---|---|
| 1차시 | 인사와 자기소개 | ~은/는 ~입니다, ~이에요/예요 | Lesson 1 |
| 2차시 | 숫자와 시간 | 한자어 수사, 고유어 수사, ~시 ~분 | Lesson 2 |
| 3차시 | 쇼핑과 가격 묻기 | 이거/저거, ~주세요, 얼마예요? | Lesson 3 |
| 4차시 | 음식 주문하기 | ~ㄹ게요, ~고 싶어요 | Lesson 4 |
| 5차시 | 길 묻기와 교통 | ~로/으로 가세요, ~ㅂ니다/습니다체 | Lesson 5 |

## 4. 공통 수업 진행 방식 (매 차시 50분)

1. **도입 (5분)** — 지난 시간 복습 인사, 오늘 학습 목표 안내
2. **어휘 제시 (10분)** — 온라인 앱의 "어휘" 탭으로 새 단어 발음·의미 학습
3. **문법 설명 (10분)** — 교사가 화면 공유로 문형 설명, 예문 제시
4. **대화 연습 (15분)** — 앱의 "대화문" 탭 활용, 짝 활동(브레이크아웃 룸)으로 역할극
5. **퀴즈·정리 (10분)** — 앱의 "연습문제" 탭으로 즉석 퀴즈, 오늘 배운 내용 요약 및 과제 안내

## 5. 평가 및 피드백

- 매 차시 종료 시 앱 내 퀴즈 점수를 기준으로 이해도 확인 (80% 이상 통과 권장)
- 학습자별 진도는 앱에 자동 저장되어 다음 수업 시작 시 복습 자료로 활용
- 5차시 종료 후 종합 말하기 평가(자기소개 + 역할극) 진행

## 6. 준비물

- 실시간 수업: 화상회의 링크, 마이크/스피커, 필기도구
- 온라인 앱: `app/index.html` (웹 브라우저로 실행, 설치 불필요)
- 보조자료: 각 차시별 지도안 PDF/인쇄물 (선택)
