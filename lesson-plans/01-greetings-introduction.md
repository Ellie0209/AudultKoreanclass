# 1차시 지도안 — 인사와 자기소개 (Greetings & Self-Introduction)

## 기본 정보

| 항목 | 내용 |
|---|---|
| 대상 | 성인 외국인 학습자 (초급, TOPIK 0급) |
| 시간 | 50분 |
| 수업 형태 | 실시간 화상 수업 |
| 학습 목표 | 1. 기본 인사말을 상황에 맞게 사용할 수 있다.<br>2. "저는 ~입니다/이에요" 문형으로 자기소개를 할 수 있다.<br>3. 존댓말의 기본 개념을 이해한다. |
| 준비물 | 온라인 앱(Lesson 1), 화면 공유, 이름표(선택) |

## 핵심 어휘

| 한국어 | 로마자 표기 | 영어 |
|---|---|---|
| 안녕하세요 | annyeonghaseyo | Hello |
| 안녕히 가세요 | annyeonghi gaseyo | Goodbye (to person leaving) |
| 안녕히 계세요 | annyeonghi gyeseyo | Goodbye (to person staying) |
| 감사합니다 | gamsahamnida | Thank you |
| 죄송합니다 | joesonghamnida | I'm sorry |
| 이름 | ireum | Name |
| 저는 | jeoneun | I (topic marker) |
| 만나서 반갑습니다 | mannaseo bangapseumnida | Nice to meet you |

## 핵심 문형

- **N은/는 N입니다** : ~은/는 명사(이)ㅂ니다 (formal)
  - 예: 저는 마이클입니다. (I am Michael.)
- **N이에요/예요** : 좀 더 부드러운 존댓말체
  - 예: 저는 마이클이에요.

## 수업 진행 (Timeline)

### 1. 도입 (5분)
- 교사가 먼저 "안녕하세요!"로 인사하며 시범을 보인다.
- 오늘의 학습 목표를 한국어와 영어로 안내한다.

### 2. 어휘 제시 (10분)
- 앱의 **Lesson 1 > 어휘** 탭을 화면 공유하며 각 단어의 발음 버튼을 눌러 함께 듣는다.
- 학습자에게 소리 내어 따라 읽도록 지도한다 (Choral repetition).

### 3. 문법 설명 (10분)
- "저는 [이름]입니다" 문형을 칠판/화면에 적고 구조를 설명한다.
- 학습자 이름을 넣어 예시를 3~4개 만들어 본다.

### 4. 대화 연습 (15분)
- 앱의 **대화문** 탭에 있는 짧은 대화를 함께 읽는다.
  ```
  A: 안녕하세요. 저는 지민이에요.
  B: 안녕하세요. 저는 마이클이에요. 만나서 반갑습니다.
  ```
- 소그룹(브레이크아웃 룸)으로 나누어 짝과 함께 자기소개 역할극을 진행한다.
- 교사는 방을 순회하며 발음과 어순을 피드백한다.

### 5. 퀴즈 및 정리 (10분)
- 앱의 **연습문제** 탭에서 5문항 퀴즈를 실시간으로 함께 풀거나 개별로 풀게 한다.
- 오늘 배운 표현을 다시 한번 소리 내어 정리한다.

## 과제

- 앱에서 Lesson 1 퀴즈를 80점 이상으로 통과하기
- 가족이나 친구에게 배운 인사말로 자기소개 해보기 (영상/음성 녹음 제출 가능)
