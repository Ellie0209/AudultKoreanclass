# 3차시 지도안 — 쇼핑과 가격 묻기 (Shopping & Asking Prices)

## 기본 정보

| 항목 | 내용 |
|---|---|
| 대상 | 성인 외국인 학습자 (초급) |
| 시간 | 50분 |
| 학습 목표 | 1. 지시대명사(이거/그거/저거)를 사용할 수 있다.<br>2. 가격을 묻고 답할 수 있다 (얼마예요?).<br>3. ~주세요 문형으로 물건을 요청할 수 있다. |
| 준비물 | 온라인 앱(Lesson 3), 화면 공유용 상품 이미지 |

## 핵심 어휘

| 한국어 | 로마자 표기 | 영어 |
|---|---|---|
| 이거 / 그거 / 저거 | igeo / geugeo / jeogeo | this / that / that (far) |
| 얼마예요? | eolmayeyo? | How much is it? |
| ~주세요 | ~juseyo | Please give me ~ |
| 원 | won | Korean won (currency) |
| 싸다 / 비싸다 | ssada / bissada | cheap / expensive |
| 시장 / 가게 | sijang / gage | market / store |

## 핵심 문형

- **이거 얼마예요?** : This, how much is it?
- **N 주세요** : Please give me N. (예: 이거 두 개 주세요.)
- **숫자 + 개/원** : 물건 개수와 가격 단위

## 수업 진행 (Timeline)

### 1. 도입 (5분)
- 지난 시간 시간 표현 복습 퀴즈 (구두로 3문제)
- 오늘 학습 목표 안내

### 2. 어휘 제시 (10분)
- 앱 **Lesson 3 > 어휘** 탭으로 지시대명사와 쇼핑 관련 단어 발음 연습
- 숫자 + 원 조합 발음 연습 (천 원, 오천 원, 만 원 등)

### 3. 문법 설명 (10분)
- "이거 얼마예요?" - "오천 원이에요." 대화 패턴 설명
- "~주세요"의 사용법과 공손함의 정도 설명

### 4. 대화 연습 (15분)
- 앱 **대화문** 탭 대화 함께 읽기:
  ```
  A: 이거 얼마예요?
  B: 그거 만 원이에요.
  A: 두 개 주세요.
  B: 네, 이만 원입니다.
  ```
- 브레이크아웃 룸에서 가상 시장 역할극 (판매자/구매자 역할 교대)

### 5. 퀴즈 및 정리 (10분)
- 앱 **연습문제** 탭 퀴즈 진행
- 배운 표현 다시 소리 내어 정리

## 과제

- 앱에서 Lesson 3 퀴즈 80점 이상 통과
- 온라인 쇼핑몰이나 마트 전단지에서 물건 3개를 골라 "이거 얼마예요?" 형식으로 문장 만들어보기
